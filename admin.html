GitHub connection

Your token is saved in this browser until you change it, so you only set this up once.

How do I get a token?
  1. On github.com click your picture, then Settings, then Developer settings.
  2. Choose Personal access tokens, then Fine-grained tokens, then Generate new token.
  3. Give it a name, set an expiry (90 days is sensible), and under Repository access choose Only select repositories, then pick cultdrip.
  4. Under Permissions, Repository permissions, set Contents to Read and write. Leave everything else as it is.
  5. Press Generate token, copy it, paste it above and press Save token.

The token can only touch this one repository. You can delete it on GitHub at any time.

Quick price tools

Change every product at once, then press Save & publish. Use “Put everything on sale” only on pieces you have really sold at the full price. Pieces set to Coming soon are skipped.

Store settings

Brand name, banner, home page words and your shop's contact details. Wording boxes left empty use the suggested wording shown in grey.

Products

Use Add product for a new item. Leave Original price at 0 when there's no sale. Paste a photo path like images/hoodie.jpg to replace the drawing.

Business details: fill in when you're ready

Anything you leave empty is simply left out of your website. Each box says where it is used.

Page words

Every box is optional. An empty box uses the suggested wording shown in grey, which updates itself from your business details. Your own words are used exactly as you write them. Put ** on both sides of words to make them bold. To link to another page on this site, write [[help.html#privacy|Privacy policy]]: the page and section first, then a bar, then the words to show.
