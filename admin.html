How it works

  1. Edit
    Change names, prices, colors, photos and stock.
  2. Save and publish
    Press the green button at the bottom. When GitHub is connected it publishes for you.
  3. Check the shop
    Your live shop updates within seconds. Use Preview first if you want to check a draft.
  4. No GitHub connection?
    Press Download data.js and upload it to GitHub yourself.

Connect to GitHub

Connect once, and every time you press Save your changes publish to the live shop automatically. No more data.js uploads.

How do I get a token?
  1. On github.com click your picture, then Settings, then Developer settings.
  2. Choose Personal access tokens, then Fine-grained tokens, then Generate new token.
  3. Give it a name, set an expiry (90 days is sensible), and under Repository access choose Only select repositories, then pick cultdrip.
  4. Under Permissions, Repository permissions, set Contents to Read and write. Leave everything else as it is.
  5. Press Generate token, copy it, paste it above and press Connect.

The token can only touch this one repository. You can delete it on GitHub at any time.
